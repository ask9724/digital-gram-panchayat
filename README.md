# ડિજિટલ ગ્રામ પંચાયત

મોબાઇલ અને કમ્પ્યુટર પર ચાલે તેવી ગુજરાતી વેબ એપ (PWA).

## હાલની સુવિધાઓ
- **આવક રજિસ્ટર:** ગ્રામ પંચાયતને મળેલી અરજીઓ, સરકારી પત્રો, ફરિયાદો અને અન્ય કાગળોની નોંધ; તારીખ, પત્ર નંબર, અરજદાર/મોકલનાર, સરનામું, વિષય, PDF/ફોટો, કોને કાર્યવાહી માટે મોકલ્યું, કાર્યવાહી, સ્થિતિ અને જવાબની વિગતો.
- **જાવક રજિસ્ટર:** ગ્રામ પંચાયત તરફથી મોકલેલા પત્રો/જવાબોની તારીખ, જાવક નંબર, મેળવનાર, સરનામું, વિષય, પત્રની PDF/ફોટો અને મોકલવાની રીત.
- આવક/જાવક નોંધોને નંબર, નામ, વિષય અથવા પત્ર નંબરથી શોધવી.
- ગ્રામ પંચાયત ઠરાવનો પ્રાથમિક ડ્રાફ્ટ અને જૂના ઠરાવમાંથી પસંદ કરેલા ભાગની અલગ નકલ.
- દસ્તાવેજો અને નોંધો સાચવવી.
- સ્ક્રીન પર સહી દોરવી અથવા સહીનું ચિત્ર ઉમેરવું.
- JSON બેકઅપ અને પુનઃસ્થાપન.

## ડેટા અને મર્યાદાઓ
- ડેટા હાલ એ જ ઉપકરણના એ જ બ્રાઉઝરમાં સંગ્રહાય છે; બીજા ઉપકરણો વચ્ચે આપમેળે સિંક થતો નથી.
- સમયાંતરે બેકઅપ ડાઉનલોડ કરો. બ્રાઉઝર ડેટા સાફ થાય અથવા ઉપકરણ ગુમાય તો બેકઅપ વિના ડેટા ગુમાઈ શકે છે.
- જોડાતી PDF/ફોટો ફાઇલ નાની રાખો; હાલ દરેક જોડાણ માટે 1 MB મર્યાદા છે.
- સહીનું ચિત્ર પ્રમાણિત Digital Signature Certificate (DSC) નથી.
- ઠરાવ જનરેટર પ્રાથમિક ડ્રાફ્ટ બનાવે છે; સત્તાવાર ઉપયોગ પહેલાં કાયદા, નિયમો અને વાસ્તવિક કાર્યવાહી મુજબ ચકાસો.
- હાલ AI API અથવા કેન્દ્રીય સુરક્ષિત ડેટાબેઝ જોડાયેલ નથી. ગોપનીય નાગરિક માહિતી નાખવા પહેલાં સુરક્ષા અને ઍક્સેસ નિયંત્રણ ઉમેરવા જરૂરી છે.
