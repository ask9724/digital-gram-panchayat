# ડિજિટલ ગ્રામ પંચાયત

મોબાઇલ અને કમ્પ્યુટર પર ઉપયોગ કરી શકાય તેવી ગુજરાતી Progressive Web App (PWA).

## સુવિધાઓ
- આવક-જાવક રજિસ્ટર: તારીખ, પ્રકાર, વિગત, રકમ અને રસીદ/વાઉચર નંબર; કુલ આવક, જાવક અને સિલક.
- ગ્રામ પંચાયત ઠરાવનો પ્રાથમિક ડ્રાફ્ટ: સભા, તારીખ, વિષય, દરખાસ્ત/ઠરાવ નંબર, ચર્ચા અને નિર્ણય.
- જૂના ઠરાવમાંથી જરૂરી ભાગની અલગ નકલ સાચવવાની સુવિધા.
- દસ્તાવેજો અને નોંધો સાચવવી.
- સ્ક્રીન પર સહી દોરવી અથવા સહીનું ચિત્ર ઉમેરવું.
- JSON બેકઅપ અને પુનઃસ્થાપન.
- ઑફલાઇન કેશિંગ.

## GitHub Pages ચાલુ કરવાની એક વખતની પ્રક્રિયા
1. Repository → Settings → Pages ખોલો.
2. Build and deployment માં **Deploy from a branch** પસંદ કરો.
3. Branch **main** અને folder **/(root)** પસંદ કરી Save કરો.
4. પ્રકાશન પૂર્ણ થયા પછી એપ અહીં ખોલો: https://ask9724.github.io/digital-gram-panchayat/

## ડેટા અને કાનૂની નોંધ
- ડેટા હાલ તે જ બ્રાઉઝરના localStorage માં રહે છે; અલગ ઉપકરણો વચ્ચે આપમેળે સિંક થતો નથી.
- બ્રાઉઝર ડેટા સાફ થાય તે પહેલાં બેકઅપ ડાઉનલોડ કરો.
- સહીનું ચિત્ર પ્રમાણિત Digital Signature Certificate (DSC) નથી.
- ઠરાવ જનરેટર પ્રાથમિક ડ્રાફ્ટ બનાવે છે; સત્તાવાર ઉપયોગ પહેલાં કાયદા, નિયમો અને વાસ્તવિક કાર્યવાહી મુજબ ચકાસો.
- હાલ AI API અથવા કેન્દ્રીય સુરક્ષિત ડેટાબેઝ જોડાયેલ નથી. ગોપનીય નાગરિક માહિતી માટે ઉપયોગ કરતાં પહેલાં સુરક્ષા અને ઍક્સેસ નિયંત્રણ ઉમેરવા જરૂરી છે.
