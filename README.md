# ડિજિટલ ગ્રામ પંચાયત

આ પ્રારંભિક PWA છે. GitHub repository માં આ ZIPની અંદરની બધી ફાઇલો (ZIP નહીં) અપલોડ કરો.

GitHub Pages ચાલુ કરવા:
1. Repository > Settings > Pages ખોલો.
2. Build and deployment માં Deploy from a branch પસંદ કરો.
3. Branch `main` અને folder `/(root)` પસંદ કરી Save કરો.
4. થોડીવાર પછી `https://ask9724.github.io/digital-gram-panchayat/` ખોલો.

નોંધ: ડેટા હાલના બ્રાઉઝરના local storage માં જ રહે છે. બ્રાઉઝર ડેટા સાફ થાય તો ડેટા ખોવાઈ શકે છે; નિયમિત બેકઅપ લો. સહીનું ચિત્ર પ્રમાણિત DSC નથી.
